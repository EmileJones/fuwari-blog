# NeoVim

## 模式切换

### `Normal-mode` **切换** `Insert-mode` **：**

| **按键** | **注释**                             |
|----------|--------------------------------------|
| i        | 在目前光标所在的前面插入             |
| I        | 在目前光标所在的行首插入             |
| a        | 在目前光标所在的后面插入             |
| A        | 在目前光标所在的行尾插入             |
| o        | 在目前光标所在的下一行处插入新的一行 |
| O        | 在目前光标所在的上一行处插入新的一行 |

### `Normal-mode` **切换** `Command-mode` **：**

| **按键**        | **注释**                                       |
|-----------------|------------------------------------------------|
| :w \[filename\] | 将编辑的数据保存成另一个文件                   |
| :! command      | 暂时退出vim到命令行模式下执行command的显示结果 |

## **复制粘贴操作**

此按键需要`Normal-mode`下执行

| **按键**     | **注释**                               |
|--------------|----------------------------------------|
| dd           | 删除（剪切）光标所在的那一整行         |
| ndd          | n为数字，删除（剪切）光标所在的向下n行 |
| yy           | 复制光标所在的那一行                   |
| nyy          | n为数字，复制光标所在的向下n行         |
| p            | 将已复制的数据粘贴在光标的下一行       |
| P            | 将已复制的数据粘贴在光标的上一行       |
| u            | 恢复前一个操作                         |
| \[Ctrl\] + r | 重做上一个操作                         |
| .            | 重复前一个操作                         |
| \[Ctrl\] + v | 可视区块，可以用矩形的方式选择数据     |

## 撤销、恢复操作

| **按键**     | **注释**                           |
|--------------|------------------------------------|
| u            | 恢复前一个操作                     |
| \[Ctrl\] + r | 重做上一个操作                     |
| .            | 重复前一个操作                     |
| \[Ctrl\] + v | 可视区块，可以用矩形的方式选择数据 |

## 查找、替换

| **按键** | **注释** |
|----|----|
| :n1,n2/word1/word2/g | n1与n2为数字，在n1与n2行之间查找word1字符串并替换为word2字符串 |
| :1,\$s/word1/word2/gc | 在本文件中查找word1字符串并替换为word2字符串，且在替换之前会显示提示字符给用户确认 |

## **多窗口功能**

| **按键**         | **注释**                                        |
|------------------|-------------------------------------------------|
| :sp \[filename\] | 打开一个新窗口                                  |
| \[Ctrl\] + w + ↓ | 光标移动到下方的窗口（先按住\[Ctrl\]+w，再按↓） |
| \[Ctrl\] + w + ↑ | 光标移动到上方的窗口（先按住\[Ctrl\]+w，再按↑） |

## 光标移动

此按键需要`Normal-mode`下执行

| **按键** | **注释**               |
|----------|------------------------|
| 0        | 跳到首行               |
| \^       | 跳到首行第一个非空字符 |
| \$       | 跳到行尾               |
| gg       | 跳到第一行             |
| G        | 跳到最后一行           |

| **按键** | **注释**                   |
|----------|----------------------------|
| w        | 跳到下一个单词开头         |
| b        | 跳到本单词或上一个单词开头 |
| e        | 跳到本单词或下一个单词结尾 |
| ge       | 跳到上一个单词结尾         |

| **按键**         | **注释**                              |
|------------------|---------------------------------------|
| \[Ctrl\] + \[f\] | 屏幕向下移动一页，相当于\[Page Down\] |
| \[Ctrl\] + \[b\] | 屏幕向上移动一页，相当于\[Page Up\]   |
| nG               | n为数字，移动到这个文件的第n行        |
| n\[Enter\]       | n为数字，光标向下移动n行              |

## 文本操作

此按键的使用方式为operator+motion，`Normal-mode`下执行

### Operator

| **按键** | **注释**              |
|----------|-----------------------|
| d        | 删除                  |
| c        | 删除并进入插入模式    |
| y        | 复制                  |
| v        | 选中并进入Visual-mode |

> d为delete，c为change，y为yank，v为visual

### Motion

| **按键**                  | **注释**       |
|---------------------------|----------------|
| `iw` / `aw`               | 选中一个单词   |
| `i(` / `a(` / `ib` / `ab` | 选中括号文本   |
| `i{` / `a{` / `iB` / `aB` | 选中大括号文本 |
| `i"` / `a"`               | 选中双引号文本 |
| `i'` / `a'`               | 选中单引号文本 |
| `` i` `` / `` a` ``       | 选中反引号文本 |
| `i<` / `a<`               | 选中尖括号文本 |
| `i[` / `a[`               | 选中方括号文本 |
| `it` / `at`               | 选中标签       |
| `is` / `as`               | 选中句子       |
| `ip` / `ap`               | 选中段落       |

> i为inner，a为around，t为tag，s为sentence，p为paragraph

## 切换大小写

此按键需要`Normal-mode`下执行

| **按键**        | **注释**                               |
|-----------------|----------------------------------------|
| `~`             | 将光标下的字母转换大小写               |
| `3~`            | 将光标位置开始的3个字母转换大小写      |
| `g~~`           | 改变当前行大小写                       |
| `gUU`           | 将当前行改变为大写                     |
| `guu`           | 将当前行改变为小写                     |
| `g~aw` / `g~iw` | 将当前单词转换大小写                   |
| `gUaw` / `gUiw` | 将当前单词转换为大写                   |
| `guaw` / `guiw` | 将当前单词转换为小写                   |
| `gUat` / `gUit` | 将标签内的文本（及标签文本）转换为大写 |
| `guat` / `guit` | 将标签内的文本（及标签文本）转换为小写 |

# Vscode Neovim

此按键需要`Normal-mode`下执行

| **按键**           | **注释**              |
|--------------------|-----------------------|
| `gd`               | 跳转到函数定义文件    |
| `gh`               | 鼠标悬浮              |
| `gt`               | 跳转到下一个标签页    |
| `gT`               | 跳转到上一个标签页    |
| `ngt`              | 跳转到第n个标签页     |
| `command/ctrl + 0` | 光标聚集到文件树      |
| `command/ctrl + n` | 光标聚集到第n个标签页 |
